# デザイン仕様「卓と牌」

麻雀の実物から色を取り、1枚の刷り物（点数早見表）のように組む。
2026-05-12 の「白×深緑ミニマル」仕様（`superpowers/specs/2026-05-12-redesign-design.md`）を置き換える。

## 考え方

このアプリが置き換えている物理オブジェクトは、雀荘に貼ってある**点数早見表**と**点棒**である。
だから画面は「アプリのダッシュボード」ではなく、**卓の上に置かれた一枚の伝票**に寄せる。

- カードを積み重ねない。**罫線と余白**で区切る
- **奥行きは1回だけ使う**。広い画面で、紙がフェルトの卓に落とす影
- 角丸は 3px。丸ピルや円形ボタンは使わない
- 中央揃えは答えだけ。条件は「ラベル｜操作」の行組み

### 三つの見せ場

平らに整えるだけでは素っ気ない紙になる。麻雀の実物にある強い絵を、
数を絞って画面に置く。

1. **フェルトの帯** — マストヘッドとモーダルの見出しを深緑で塗り、
   牌の背を思わせる細い斜線のテクスチャを重ねる。画面の顔になる
2. **朱の判** — 満貫以上のとき、点数の下に角印を捺す。縦組み・わずかに傾ける。
   状態表示ではなく「印」なので、朱はこことマストヘッドの牌にだけ使う
3. **伝票の作り** — 答えの欄は隅に見当（トンボ）を置き、支払いの内訳を罫で囲った明細にする

## 色

実物から取る。雀卓のフェルト（深緑）、牌の象牙、墨、中の朱。

**紙は一枚だけ。ダークモードは持たない。**
卓上で見るものなので、紙として一貫していたほうが読み違えにくい。
`<meta name="color-scheme" content="light">` を宣言し、OS がダークでも
フォーム部品が勝手に暗くならないようにしてある。

| トークン | 値 | 役割 |
|---|---|---|
| `--table` | `#21432f` | 雀卓。広い画面で紙の外側に見える |
| `--ground` | `#eeefe9` | 紙の外側の地（狭い画面） |
| `--sheet` | `#fdfcf9` | 伝票の面。純白にはしない（純白は生成デザインの既定色でもある） |
| `--raise` | `#f3f3ec` | 答えの欄、表の見出し |
| `--ink` | `#21261f` | 墨（本文） |
| `--ink-2` | `#59614f` | 副次の文字 |
| `--ink-3` | `#8a9384` | 無効な記号 |
| `--rule` / `--rule-strong` | `#cbd2c5` / `#a9b3a2` | 罫線・枠 |
| `--felt` | `#2e5d45` | 雀卓の緑。**選択状態と主要な罫だけ** |
| `--felt-ink` | `#2e5d45` | 緑を文字色に使うとき |
| `--vermilion` | `#a83a25` | 中の朱。**満貫以上の判だけ** |
| `--warn-*` | 芥子色 | 注意書き |

色は役割で分ける。朱は満貫以上のときだけ現れる。ふだんは画面に朱が無いのが正しい。

## 書体

端末に入っている和文書体を使う。webフォントは読まない
（雀荘で電波が悪いときに待たされる／字形が差し替わるのを避けるため）。

- `--mincho` — Hiragino Mincho ProN → Yu Mincho → Noto Serif CJK JP → serif
  **見出し・点数・「合計」だけ**に使う。使いすぎると読みにくくなる
- `--gothic` — システムの和文ゴシック。本文とUI全般

サイズは `--fs-xs` 12px / `--fs-sm` 13px / `--fs-md` 15px / `--fs-lg` 17px / 点数 3.1rem の5段だけ。

日本語ラベルに `text-transform: uppercase` を使わない（効かない上に字間だけが不自然になる）。

## 状態の表し方

- **選択中** — フェルトの塗り＋`--on-felt` の文字。内側に影を落として押し込まれたキーに見せる
- **無効** — 45度の斜線（`repeating-linear-gradient`）。不透明度で薄くしない。
  不透明度で薄くすると、無効なのか単に見づらいのかが分からなくなる
- **注意** — 芥子色の地に左罫。状態表示（罫線で区切っただけの帯）と見分けがつくようにする

## 守ること

- 全テキストが WCAG AA（4.5:1）以上
- タップ領域は 40px 以上
- ピンチズームは殺さない。ダブルタップ拡大だけを `touch-action: manipulation` で止める
- 絵文字を見出しに使わない
- 括弧は全角、並列は中黒（`三元・自風・場風`）。半角括弧と ASCII スラッシュを混ぜない
- 節の見出しは書体ではなく**見出し罫**で作る。小さい明朝は字面が潰れて意味がない
- 明朝は「見出しと答え」だけ。早見表のような一覧の数字はゴシックのまま揃える
