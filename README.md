# 麻雀点数計算機

[🀄 Web版を開く](https://ryota-kashi.github.io/mahjong-calculator/)

翻数と符数を選択するだけで、親・子、ロン・ツモに応じた点数をリアルタイムに算出するシンプルな麻雀点数計算機です。

## 主な機能

- **点数計算**: 1翻〜役満、20符〜110符まで対応
- **符計算アシスト**: 雀頭・待ち・面子の構成をタップするだけで符を自動計算
- **本場管理**: 積み棒（本場）を含めた支払い点数の算出
- **ツモ支払い表示**: ツモ時は子・親それぞれの支払い額を個別に表示
- **リアルタイム反映**: 設定変更で即座に計算結果を更新

## 技術スタック

- HTML5 / CSS3 / JavaScript (ES6+)
- 静的サイト — サーバー不要、GitHub Pages でホスティング

## 使い方

1. **親/子の選択**: 東（親）か南（子）を選択
2. **アガリ方の選択**: ロンまたはツモを選択
3. **翻数・符数の選択**: ドロップダウンから選択
4. **符数が不明な場合**: 「符数計算アシスト」から手牌の状態を入力して反映
5. **本場の設定**: 積み棒がある場合は本場数を調整
