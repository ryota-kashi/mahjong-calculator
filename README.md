# 麻雀点数計算機

[🀄 Web版を開く](https://ryota-kashi.github.io/mahjong-calculator/)

翻数と符数を選択するだけで、親・子、ロン・ツモに応じた点数をリアルタイムに算出するシンプルな麻雀点数計算機です。

## 主な機能

- **点数計算**: 1翻〜ダブル役満、20符〜110符まで対応（切り上げ満貫なし・基本点2000打ち切り）
- **翻数計算アシスト**: 成立した役をタップするだけで翻数を自動計算
  - 鳴くと門前限定役を自動で無効化。三色・一通・混一色などは食い下がり後の翻数に切り替え
  - 海底摸月・嶺上開花はツモ限定、河底撈魚・槍槓はロン限定。天和は親、地和は子のみ
  - 一発と裏ドラはリーチが前提。ドラだけでは役がないため反映できない
  - 役満は複合して加算（大三元＋字一色＝ダブル役満）。四暗刻単騎・国士無双十三面・純正九蓮宝燈もダブル役満
  - 数え役満は何翻あっても役満1つ分
  - 平和と対々和のように同時に成立しない組み合わせを警告
- **点数早見表**: 翻×符のマトリクスを親子・ロン/ツモで表示。マスをタップすると本体に反映
- **符計算アシスト**: 雀頭・待ち・面子の構成をタップするだけで符を自動計算
  - 七対子25符固定、平和ツモ20符、喰い平和ロン30符の特例に対応
  - 門前と明刻・明カンの矛盾入力を防止（明カンや2つ目の明刻を入れると自動で「鳴き」に）
  - 面子は雀頭を除いて4つまでに制限
  - ロン／ツモを切り替えると符を自動で再計算
- **門前／鳴きをメイン画面に集約**: 翻数と符の両方に効く条件なので、両アシストが同じ設定を共有します
- **七対子は翻数と符で自動同期**: どちらで選んでも2翻25符になります
- **アクセシビリティ**: 全テキストが WCAG AA（コントラスト4.5:1）以上、タップ領域は40px以上、
  キーボードのみで全機能を操作可能（モーダルはフォーカストラップと復帰つき）、ピンチズーム可
- **不成立の組み合わせを防止**: 20符ロン、1翻20符、1翻25符は選択不可。5翻以上は符欄を無効化
- **本場管理**: 積み棒（本場）を含めた支払い点数の算出（ロン+300点/本場、ツモ各家+100点/本場）
- **ツモ支払い表示**: ツモ時は子・親それぞれの支払い額を個別に表示
- **リアルタイム反映**: 設定変更で即座に計算結果を更新

## 技術スタック

- HTML5 / CSS3 / JavaScript (ES6+)
- 静的サイト — サーバー不要、GitHub Pages でホスティング

## 使い方

1. **親/子の選択**: 東（親）か南（子）を選択
2. **アガリ方の選択**: ロンまたはツモを選択
3. **手の状態の選択**: 門前か鳴きかを選択
4. **翻数・符数の選択**: ドロップダウンから選択
5. **翻数が不明な場合**: 「翻数計算アシスト」から成立した役をタップして反映
6. **符数が不明な場合**: 「符数計算アシスト」から手牌の状態を入力して反映
7. **本場の設定**: 積み棒がある場合は本場数を調整

ヘッダーの表アイコンから点数早見表を開けます。

## 開発

```bash
npm install
npx playwright install chromium
npm test
```

`tests/score.test.mjs` は実際のブラウザで `index.html` を動かし、点数計算・符計算アシスト・
翻数計算アシスト・翻符のバリデーション・早見表を標準的なリーチ麻雀のルールと照合します。
最後にランダム操作を2000回繰り返して、状態どうしが矛盾しないことも確認します。
GitHub Actions で push / pull request ごとに実行されます。

## 設計メモ

状態を変えるのはイベントハンドラだけです。ハンドラは最後に `commit()` を呼び、
`commit()` が `normalize()`（状態どうしの整合を取る）→ `render()`（画面を描く）の順で回します。
`render` 系の関数は状態を書き換えません。この一方向の流れによって、
「符アシストを開いただけで本体の状態が変わる」「関数ごとに呼び出し順序が違って1周遅れる」
といった不具合が構造的に起きないようにしています。
